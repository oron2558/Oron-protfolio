Accessibility statement

This site is built to be usable by everyone. It follows the Israeli Equal Rights for Persons with Disabilities (Service Accessibility Adjustments) Regulations, 5773-2013, and Israeli Standard IS 5568, based on WCAG 2.0 level AA. It was also built to WCAG 2.1 level AA.

What has been done

  • Full keyboard navigation with a visible focus indicator.
  • Text alternatives for images and a clear heading structure for screen readers.
  • Colour contrast checked against the standard.
  • A Sound on control for the hero video, which starts muted.
  • Respect for the device's Reduce motion setting.
  • Layouts for phone, tablet and desktop, with support for 200% text zoom.

No third-party accessibility overlay is used: the adjustments are built into the code and work with your device's and browser's own accessibility settings and with screen readers.

Known limitations

  • Some case-study images are screenshots of product interfaces. The key points are also described in the text around them.

Found a problem?

If anything on the site is not accessible to you, I want to hear about it and fix it. Please mention the page, what you tried to do and which device and browser you used.
